## Что сделано

Различение РОЛЕЙ поверхностей в карточке ревью: полоса окружения стала утопленной
справочной панелью, отделённой от обведённых кнопок-кандидатов. Один файл —
`ContextStrip.tsx` (+ тест). Семантика границы раздела из 3.5 §4 не менялась.

- **Утопленная поверхность + подпись + воздух** (Task 1). Корневой контейнер полосы
  залит sunken-токеном `bg-[var(--ds-surface-sunken)]` (переиспользован токен, не
  литерал); первым элементом — подпись «Окружение в смете» тем же типографическим
  словарём, что подпись разделителя «Раздел — …»; нижний отступ `mb-4` даёт паузу
  «читаю → выбираю». Регресс-гвард: строки полосы не несут словаря кандидата
  (`rounded-md`/`border-border`).
- **Правая часть присвоенного соседа — код статьи** (Task 2). Confirmed-сосед
  показывает `→ {код}` моноширинным, полное имя ушло в нативный `title` (`rightSide`:
  `string → {text, title?, mono?}`). Однородный раздел больше не повторяет длинный
  хвост имени статьи в каждой строке. Статусные подписи неприсвоенных — без изменений.
  Осознанный trade-off: `title` недоступен с клавиатуры/тача (пересмотр — по жалобе).
- **Кромка-резерв активной строки** (Task 3). `border-l-2 border-transparent` на
  КАЖДОЙ строке, активная перекрашивает тон (`border-primary`); резерв ширины на всех
  строках убирает горизонтальный «дёрг» контента при движении очереди. Тинт и маркер
  `ArrowLeft` сохранены.
- **Иерархия тонов имени** (Task 5 + Task 6, решение #6, по живому гейту). Имя
  рядового **не-muted** соседа (не активная, не открывашка) приглушено
  `text-[var(--ds-text-2)]`; открывашка, активная и excluded/pending — полный тон
  (условие `!openers[g] && !active && !muted`). Вторая ось открывашки достигнута
  **приглушением окружения**, а не подъёмом открывашки — ни один класс открывашки
  (`font-medium`) не тронут, изгородь 3.5 цела, парный тест самообъявления зелёный
  без правок. excluded/pending исключены (`!muted`): у них уже есть ось «тихо» —
  `opacity-60`; тон был бы двойным кодированием.

## Процесс: subagent-driven, две поправки спеки по живому гейту

Исполнение — subagent-driven (Sonnet-исполнитель, Opus task-ревью на каждую задачу +
финальный whole-branch ревью). Живой гейт дал два открытия, оба зафиксированы
поправками СПЕКИ (решение #6), а не устным согласием:

1. **Вес открывашек на sunken** (→ Task 5). `font-medium` в 11.5px против regular на
   `#110D1C` — на грани. Ключевой принцип: приглушать фон, а не поднимать фигуру —
   так изгородь 3.5 не двигается вовсе. Отвергнут `text-primary` открывашкам
   (фиолетовый в полосе — язык позиции, не структуры) и `font-semibold` (двигал бы
   класс открывашки).
2. **Двойное затухание excluded** (→ Task 6). Приглушать тоном строку, у которой уже
   есть `opacity-60`, — двойное кодирование. API-скан всех 4 загруженных смет
   (id 20/18/16/15): 73 excluded-строки, **0 не-открывашек** → двойное затухание в
   реальных данных не возникает вовсе; `!muted` закрывает и теоретический хвост
   (excluded-лист без детей) по конструкции.
