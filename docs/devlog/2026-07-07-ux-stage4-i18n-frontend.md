## Контракт кодов ↔ словарь (§4.4, PR-1 + PR-2)

Бэкенд (PR-1, PR #32) отдаёт машинный `code` в теле ошибки рядом с `detail`; `ApiError.code` его
несёт. `apiErrorText(err, t, fallbackKey)` — единая цепочка показа: `t("errors."+code)` (если ключ
есть в словаре) → русский `detail` бэка (как есть, не переводится — это уже готовый текст с сервера)
→ `t("errors.generic")`; для не-`ApiError` — экранный `fallbackKey`. Секция `errors.*` намеренно БЕЗ
интерполяций: конкретика (значения) остаётся в бэковом `detail` или на самом экране формы.
Персист-статус баннера сметы (`statuses.{status_code}` — snake_case ключи, т.к. `status_code` из
БД snake_case) — отдельная, более узкая ветка того же принципа «код → ключ словаря».

## Ключевые решения

- **Не-React точки не зовут `t()`:** `statusLabel()` ([reviewState.ts](../../frontend/src/lib/reviewState.ts))
  возвращает i18n-**ключ**, не текст; рендерящий компонент сам зовёт `t(key)` — подписка на смену
  языка остаётся на стороне компонента, чистая функция остаётся чистой.
- **Один статус — один ключ:** `statuses.*`/`structure.*` — общие секции; `STATUS_META`, `statusLabel`,
  грид, полоса контекста, `StructureNotice` ссылаются на одни и те же ключи (никаких `statuses.grid.*`
  дублей).
- **Экспортное имя `_matched.xlsx`** — нейтральный латинский суффикс вместо кириллического
  `_сопоставлено.xlsx` (константа, НЕ из словаря — filesystem-safe независимо от языка интерфейса;
  санкционированное изменение поведения).
- **Локализованный confirm-word** (`WipeCatalog`) — слово-подтверждение читается из словаря
  (`articles.wipeConfirmWord`: ru «УДАЛИТЬ» / tr «SİL»), сравнение с вводом — через `t()`, а не
  захардкоженную строку.
- **Native-плюрализация** (i18next `_one/_few/_many/_other` для ru, `_one/_other` для tr) заменила
  самописный `pluralizeRu` (`lib/plural.ts` — удалён после миграции последнего вызова). Тест
  `plural.test.ts` покрывает обе локали.
- **`localStorage["ciw.ui.lang"]`** — выбор языка персистируется отдельно от JWT (который живёт
  только в `sessionStorage` — правило не нарушено); переживает логаут. Переключатель RU/TR — в
  меню `AppShell`; `document.documentElement.lang` синхронизируется на `languageChanged`.

## Верификация (Task 9, финальный гейт)

Из `frontend/`:
- `npm run typecheck` (`tsc -b --noEmit`) — **0 ошибок**.
- `npx vitest run` — **37 файлов, 270 тестов, все PASS** (включая `parity.test.ts`, `plural.test.ts`,
  `i18n.test.ts`, `formatDate.test.ts`, `errorText.test.ts`).
- `npm run build` — **успешно** (`tsc -b && vite build`; предупреждение о размере чанка и
  plugin-timings — не связано с i18n, существующая характеристика сборки).

Из корня:
- `just lint` — ruff (`backend`) чист; eslint (`frontend`) — **0 ошибок**, 1 warning (известный
  pre-existing `useVirtualizer`/`react-hooks/incompatible-library` на `ReviewGrid.tsx:75`, не
  относится к i18n); prettier `--check` — чист.
